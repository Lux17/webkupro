3. Detail Bukti Retest

3.1 Whitebox — PT-05 XSS

  • app/Support/HtmlSanitizer.php aktif
  • EpisodeController memanggil sanitizer saat simpan & tampil (7 call sites)
  • View masih memakai {!! $content !!} tetapi input sudah dibersihkan (defense-in-depth + CSP)

Unit test payload:

<script>alert(1)</script>          → dihapus (PASS)
<img onerror=alert(1)>               → atribut on* dibuang (PASS)
href="javascript:..."                → href dibuang (PASS)
style url(javascript:...)            → style dibuang (PASS)
onclick=...                          → dibuang (PASS)

3.2 Whitebox — PT-07 Mass assignment

  • User::$fillable tidak memuat rolename (PASS)
  • Register: $user->rolename = 'pengguna' dipaksa server-side
  • Admin/Guru/Pengguna controller set role literal, bukan $request->rolename

3.3 Whitebox — PT-11 Upload

  • Tidak ada max:102400000 di controller
  • Tidak ada getClientOriginalName() di controller upload
  • Whitelist: mimes:jpg,jpeg,png,...,zip + max:10240
  • public/upload/.htaccess memblokir eksekusi PHP

3.4 Whitebox — PT-12 Kuis

  • ResultController / KuisController@hasil / QuizController: auth, role siswa, binding kelas, mapel server-side
  • Skor dihitung dari total soal DB, bukan jumlah jawaban client
  • Attempt existing tidak di-overwrite

3.5 Blackbox — Header & exposure

GET /login
  X-Frame-Options: SAMEORIGIN
  X-Content-Type-Options: nosniff
  Referrer-Policy: strict-origin-when-cross-origin
  Permissions-Policy: camera=(), microphone=(), geolocation=()
  Content-Security-Policy: default-src 'self'; ...
  (X-Powered-By: tidak ada)
